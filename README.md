# Monkeytype Racer

Race quotes with friends or practice solo. [monkeytyperacer.com](https://monkeytyperacer.com)

```sh
pnpm install
pnpm dev --port 3002
```

Practice works without a database. For accounts and racing, set `DATABASE_URL` in `.env.local` and run `pnpm db:migrate`.
